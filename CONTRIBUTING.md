# Contributing Guidelines

Thank you for your interest in this project! 

This repository is primarily maintained as a personal portfolio project and template. While active feature contributions (like PRs adding new sections to the core template) are not regularly expected or required, you are **highly encouraged to fork this repository** and customize it for your own personal use!

## How to use this project

1. **Fork the repository**: Click the "Fork" button at the top right of this page to create your own copy.
2. **Clone your fork**: `git clone https://github.com/YOUR_USERNAME/portfolio.git`
3. **Customize it**: Add your own flair! Change the colors, swap out the 3D models in the Hero section, modify the AI prompts, and update the data via the Admin panel.
4. **Deploy**: Follow the deployment instructions in the `README.md` to get your portfolio live.

## Reporting Issues

If you find a reproducible bug or have a suggestion for a significant improvement to the core template, feel free to open an Issue. Please include:
- A clear description of the problem.
- Steps to reproduce the issue.
- Any relevant logs or screenshots.

## Pull Requests

If you do want to submit a Pull Request (e.g., bug fixes, typos, or highly requested features):
- Please open an issue first to discuss the proposed changes.
- Ensure your code follows the existing style and linting rules (`npm run lint`).
- Keep PRs focused on a single change or feature.

Happy coding!
